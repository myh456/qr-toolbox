# <img src="public/icon/32.png" width="20" alt="二维码工具箱图标"> 二维码工具箱

一个轻量、便捷的浏览器二维码工具，集二维码生成、网页二维码识别、内容复制与图片保存于一体。

## ✨ 功能特性

- **当前网站生成二维码**：一键将当前浏览网页的 URL 转换为二维码。
- **自定义文本生成二维码**：支持输入任意文本或网址，快速生成对应二维码。
- **网页二维码解析**：通过鼠标框选网页中的任意矩形区域，自动识别其中的二维码。
- **复制解析结果**：一键复制识别出的二维码内容。
- **保存二维码**：将生成的二维码保存为图片，方便分享和使用。

## 📦 安装说明

### 关于发布方式

由于本人目前无法支付 Chrome Web Store 开发者账号的注册费用，因此暂时无法通过 Chrome 网上应用店发布本插件，目前采用自行分发的方式提供插件。

### Windows 安装配置

**1. 打包并生成crx**

运行 `npm run build` 命令，将项目打包。
打开chrome，开启扩展程序开发者模式，选择打包扩展程序，将`.output/chrome-mv3`文件夹打包成crx。

**2. 获取扩展 ID**

将打包好的crx文件拖到浏览器中进行安装，并选择保留。
获取需要安装的扩展 ID，通常是一个由 32 个小写字母组成的字符串。

**2. 以管理员身份打开命令提示符（CMD）**

**3. 执行以下命令**

```bat
reg add "HKLM\SOFTWARE\Policies\Google\Chrome\ExtensionInstallAllowlist" /v "1" /t REG_SZ /d "xxx..." /f
```

将命令中的 `xxx...` 替换为实际的扩展 ID。

**4. 重启 Chrome 浏览器**

完成配置后，重新启动浏览器，并启用插件。

> **注意：**
>
> - 上述命令需要管理员权限。
> - `ExtensionInstallAllowlist` 用于配置允许安装的扩展 ID，本身不会自动下载或安装插件。
> - 如果设备由组织统一管理，相关策略可能受到管理员控制，修改前请确认你有相应权限。
> - 如果使用其他 Chromium 内核浏览器，需要根据浏览器对应的策略路径进行配置。
